# Hardware

Hardware source files are being developed.

Planned subdirectories:
- `kicad/`: schematic, PCB, fabrication outputs, and design notes.
- `electrode/`: IDE geometry variants A/B/C and sample chamber notes.
- `bom/`: bill of materials with manufacturer part numbers and sourcing notes.

No fabrication-ready KiCad design is included yet. Do not treat the proposed pin map or electrode dimensions in the README as a verified finished design.
