# XIAO ESP32-S3 firmware

Firmware is planned for PlatformIO + Arduino.

Planned V1 functions:
- FDC1004 I2C identity check and capacitance acquisition.
- NTC temperature measurement.
- SSD1306 display.
- Timestamped CSV over USB serial.

The firmware source has not yet been added or bench-verified. Do not infer TPC or provide food-safety classifications from raw capacitance.
