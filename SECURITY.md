# Security Policy

Report vulnerabilities involving firmware update paths, exposed credentials, unsafe interfaces, or repository infrastructure privately through GitHub's private vulnerability reporting feature, where enabled.

Do not publish Wi-Fi credentials, API keys, personal data, or private contact details in issues or commits.

The prototype is not a certified measuring instrument or safety device. Review power, grounding, exposed conductors, enclosure, and sample-contact risks before testing. Do not use it to make food-safety decisions.
