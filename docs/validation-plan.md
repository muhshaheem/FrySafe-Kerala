# Validation plan

## Gate 0 — Electronics

- Confirm FDC1004 manufacturer and device ID.
- Confirm repeatable register reads and valid measurement completion.
- Check thermistor readings against a reference thermometer.
- Measure baseline noise and drift.

## Gate 1 — Electrode feasibility

Compare IDE variants A/B/C using the same chamber and controlled conditions. Document fabrication tolerances, board finish, cleaning, and handling. Repeat across multiple sessions.

## Gate 2 — Temperature and confounders

Vary temperature in controlled increments. Assess sample placement, moisture, residue, cleaning, and instrument warm-up. Record uncontrolled conditions rather than ignoring them.

## Gate 3 — Reference method

Find a university or competent food-testing laboratory. Agree on a reference method before collecting calibration data. Determine whether the lab can measure TPC in the intended matrix and whether extracted lipid from fried food is analytically meaningful.

Do not perform solvent extraction outside a properly equipped laboratory with trained supervision.

## Gate 4 — Independent evaluation

Use independent batches for calibration and held-out evaluation. Avoid data leakage from repeated readings of the same batch. Report sample count, matrix, conditions, calibration procedure, error metrics, uncertainty, failure cases, and operating limits.

## Exit criteria

A narrow quantitative claim requires independent comparison against a suitable reference method across the intended operating range. Regulatory use requires separate assessment and approval.
